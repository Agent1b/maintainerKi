# maintainerKi v0.1.0-beta.2 — Verified Public Beta

This release supersedes `v0.1.0-beta.1` and contains the same first-public-beta product scope with corrected GitHub Actions and release metadata.

## Fixes since beta.1

- Dashboard Playwright E2E now starts the backend with an absolute GitHub workspace Python path.
- CI includes regression coverage for the E2E virtualenv path contract.
- Beta tags are published as GitHub prereleases automatically.

## Included beta scope

- GitHub webhook intake for issues and pull requests
- Signature verification, replay/idempotency handling, repository filtering, and stale-event protection
- Async scoring with FastAPI, Celery, PostgreSQL, and Redis
- `ollama`, `mlx`, and `mock` scoring providers
- Duplicate detection, contributor-history context, and optional GitHub enrichment
- Maintainer dashboard with inbox, detail view, filtering, stats, feedback, and authentication
- Optional, default-off GitHub write-back limited to deterministic `maintainerki:*` labels
- Self-hosted Docker Compose deployment, production smoke tests, and audited source snapshots

## Deployment model

This beta remains self-hosted, single-admin, and bring-your-own GitHub App/model provider. It is not a hosted multi-tenant SaaS or an autonomous moderation service.

Start with `README.md`, then follow `docs/INSTALLATION.md`, `docs/CONFIGURATION.md`, and `docs/DEPLOYMENT.md`.
