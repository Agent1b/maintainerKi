# maintainerKi v0.1.0-beta.3 — CI-Verified Public Beta

This release supersedes `v0.1.0-beta.2` and is the first public beta validated by the complete hosted GitHub Actions pipeline.

## Fixes since beta.2

- The ephemeral GitHub App private key used by the production-stack smoke test is readable by the intentionally non-root application container.
- CI includes a regression contract for that key-mount permission boundary.
- The hosted production-like Docker Compose stack now reaches readiness and completes its authenticated API and webhook smoke checks.

## Verification scope

- Backend test suite
- Dashboard lint and production build
- Dashboard Playwright E2E
- Python and npm production dependency audits
- Production and hosted Compose configuration rendering
- Production-like PostgreSQL, Redis, Celery, FastAPI, and dashboard stack smoke test
- Audited source snapshot generation from tracked Git files

## Product scope

maintainerKi is a self-hosted GitHub triage assistant for issues and pull requests. It supports `ollama`, `mlx`, and `mock` scoring providers, durable webhook processing, duplicate detection, contributor-history context, an authenticated maintainer dashboard, and optional default-off GitHub write-back restricted to deterministic `maintainerki:*` labels.

This beta remains single-admin and bring-your-own GitHub App/model provider. It is not a hosted multi-tenant SaaS or an autonomous moderation service.

Start with `README.md`, then follow `docs/INSTALLATION.md`, `docs/CONFIGURATION.md`, and `docs/DEPLOYMENT.md`.
