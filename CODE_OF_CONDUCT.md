# Code of Conduct

## Our standard

maintainerKi is a small open-source project for maintainers and contributors who want practical, respectful collaboration.

Please:

- be respectful and direct
- assume good intent before escalating
- keep criticism concrete and tied to the code, docs, or workflow
- avoid harassment, personal attacks, discrimination, or intimidation
- avoid posting secrets, exploit details, or sensitive security material in public threads

## Scope

This applies to:

- GitHub issues
- pull requests
- discussions
- review comments
- any project-managed community space tied to maintainerKi

## Enforcement

Project maintainers may edit, hide, lock, or remove content that breaks this code of conduct, and may limit participation for repeated or severe violations.

## Security-sensitive topics

If something is security-sensitive, do not turn it into a public argument or public disclosure. Follow `SECURITY.md` and use a private reporting path first.

## Reporting conduct issues

If a conduct problem involves a public thread, open a private contact path with the project maintainer instead of escalating it publicly.
